# emit-sds-l3rfl

Welcome to the EMIT Level 3 Gridded Reflectance science data system repository. To understand how this repository is linked to the rest of the emit-sds repositories, please see [the repository guide](https://github.com/emit-sds/emit-main/wiki/Repository-Guide).

L3RFL consists of two components:

1. Nearest-neighbor gridding of L2A reflectance products onto a regular WGS-84 lat/lon grid
2. Conversion of the gridded products to DAAC-compatible netCDF4, with supporting metadata and a browse image
